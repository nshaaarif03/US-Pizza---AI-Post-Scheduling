# AI Social Media Planner

The Laravel application is in [`planner/`](planner/).

See [`planner/README.md`](planner/README.md) for installation, MySQL configuration, Gemini setup, project structure, testing, and the complete demonstration workflow.

The local demo was configured at **http://127.0.0.1:8000** with an isolated MariaDB instance on port **3307**. Both processes must be running to use it. Standard installation uses your own MySQL server on port 3306.

No official logo file or Gemini API key was included in the supplied attachments. A temporary text wordmark and clearly labeled sample content are provided.
